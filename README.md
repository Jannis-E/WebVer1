# WebVer1

Static site for **Aurora Studio**, a web design studio, with four landing-page
mockups linked from its Works section.

Live: https://jannis-e.github.io/WebVer1/ (GitHub Pages)

## Layout

| Path | Page |
|---|---|
| `index.html`, `style.css`, `script.js` | Aurora Studio home page |
| `sub/cafe/` | The Corner Cafe |
| `sub/colorful/` | Colorful hair salon |
| `sub/gardens/` | High-Quality Gardens |
| `sub/nordpole/` | Nordpole Consulting |

Plain HTML, CSS and JavaScript; no build step.

## Run locally

```bash
python -m http.server 5500
```

Then open http://localhost:5500.
